Firestore Collections

users/{uid}
  • role: "vendor" | "customer"
  • displayName: string
  • email: string
  • vendor only:
  • storeName: string
  • address: string
  • storeDescription: string
listings/{listingId}
  • vendorId: string
  • type: "mystery_box" | "item"
  • title: string
  • description: string
  • price: number
  • originalPrice: number
  • quantityTotal: number
  • quantityRemaining: number ⚡
  • pickupStart: timestamp
  • pickupEnd: timestamp
  • category: string
  • status: "active"|"sold_out"|"expired"
orders/{orderId}
  • customerId: string
  • vendorId: string
  • listingId: string
  • listingTitle: string
  • quantity: number
  • totalPrice: number
  • status: "paid"|"picked_up"|"cancelled"
  • qrCode: string (UUID)
  • createdAt: timestamp

⚡ = decremented via Firestore transaction to prevent overselling under concurrent purchases
