Bilingual Strategy (react-i18next)

Translation Files
  • src/locales/en/translation.json
  • src/locales/vi/translation.json
  • Loaded at app init via i18next
  • Fallback: en if key missing in VI
Language Toggle Behaviour
  • Toggle in header (both layouts)
  • Saves preference to users/{uid}.lang
  • Loaded from Firestore on login
  • Falls back to browser navigator.language
Usage in components

const { t } = useTranslation();
<button>{t('listing.buyNow')}</button>
// en: "Buy Now" · vi: "Mua ngay"
