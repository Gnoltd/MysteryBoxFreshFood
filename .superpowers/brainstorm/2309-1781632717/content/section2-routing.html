Section 2 — Page Structure & Routing

React Router v6 · Role-based layouts · Protected routes

Route Map

Auth (public)
  • /login
  • /register — role selector (vendor / customer)
Customer (role: customer)
  • /browse — listings feed + filter
  • /listing/:id — detail + buy
  • /checkout/success — Stripe return
  • /checkout/cancel — Stripe return
  • /orders — order history
  • /orders/:id — QR code display
Vendor (role: vendor)
  • /vendor — dashboard (stats)
  • /vendor/listings — manage listings
  • /vendor/listings/new — create listing
  • /vendor/listings/:id/edit — edit listing
  • /vendor/orders — incoming orders
  • /vendor/scan — QR scanner

Layout Tree

App
├─ AuthLayout (no nav)
├─ /login
└─ /register
├─ CustomerLayout (top nav + lang toggle)
└─ ProtectedRoute role="customer"
├─ /browse, /listing/:id
├─ /checkout/success, /checkout/cancel
└─ /orders, /orders/:id
└─ VendorLayout (sidebar nav + lang toggle)
└─ ProtectedRoute role="vendor"
├─ /vendor (dashboard)
├─ /vendor/listings, /new, /:id/edit
├─ /vendor/orders
└─ /vendor/scan

Customer gets a top nav bar (mobile-friendly). Vendor gets a sidebar (dashboard-style). Both share the same auth system and language toggle.
