Section 1 — Architecture & Data Model

Single SPA · React/Vite + TypeScript · Firebase Auth + Firestore + Cloud Functions · Stripe Test Mode

App Structure

Auth Layer

Firebase Auth (email/password)
AuthContext (React)
Role stored in Firestore users/{uid}

Routing

React Router v6
ProtectedRoute (auth guard)
RoleRoute (vendor/customer)

Real-time Data

Firestore onSnapshot
Transactions for stock decrement
No manual refresh needed

Payment + Webhook

Stripe Checkout (test mode)
Firebase Cloud Function
Webhook → creates order in Firestore

Firestore Collections

users/{uid}
  • role: "vendor" | "customer"
  • displayName: string
  • email: string
  • lang: "en" | "vi"
  • vendor only:
  • storeName: string
  • address: string
  • storeDescription: string
listings/{listingId}
  • vendorId: string
  • type: "mystery_box" | "item"
  • title: string
  • description: string
  • price: number (VND)
  • originalPrice: number
  • quantityTotal: number
  • quantityRemaining: number ⚡
  • pickupStart: timestamp
  • pickupEnd: timestamp
  • category: string
  • imageUrl: string
  • status: "active" | "sold_out" | "expired"
  • stripeProductId: string
  • stripePriceId: string
orders/{orderId}
  • customerId: string
  • vendorId: string
  • listingId: string
  • listingTitle: string
  • quantity: number
  • totalPrice: number
  • status: "pending" | "paid" | "picked_up" | "cancelled"
  • qrCode: string (UUID v4)
  • stripeSessionId: string
  • createdAt: timestamp

⚡ = decremented via Firestore transaction to prevent overselling · Orders created by Cloud Function on Stripe webhook, never by client

New vs. previous session

  • Added lang field to users (EN/VI preference)
  • Added imageUrl to listings
  • Added stripeProductId / stripePriceId to listings
  • Added stripeSessionId to orders
  • Order status now starts as "pending" (created at checkout initiation) → "paid" (webhook) → "picked_up"
